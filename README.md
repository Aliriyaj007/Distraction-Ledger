## 🎯 The Problem
We often finish a workday feeling exhausted but unproductive, unable to explain where the hours went. Traditional productivity tools try to **force** focus through blocking, which often leads to frustration and disabling the blocker.

## 💡 The Solution
**Awareness over enforcement.** By manually logging a distraction with a single click, you create a "mindfulness gap." Over time, the act of logging becomes a friction point that reduces the urge to be distracted.

### Impact: Before vs. After

| **Metric** | **Before Distraction Ledger** | **After Distraction Ledger** |
| :--- | :--- | :--- |
| **Focus** | Fragmented, reactive. | Intentional, protected. |
| **Data** | "I felt busy today." | "I lost 42 mins to social media between 2-3 PM." |
| **Feeling** | Guilt about lost time. | Clarity on habits and triggers. |
| **Privacy** | Data sold to advertisers. | **Data never leaves your device.** |

## ✨ Key Features

The application is contained entirely within a single `index.html` file. No database. No tracking. No API calls.

*   **⚡ Zero Latency:** Logs distractions instantly.
*   **🎨 12+ Themes:** Includes *Hacker, Nord, Dracula, Cyberpunk, Midnight*, and more.
*   **📊 Visual Analytics:** Real-time charts for daily distribution and 7-day trends.
*   **🔒 Offline-First:** Uses `localStorage`. Works on planes, trains, and disconnected environments.
*   **💾 Data Sovereignty:** Full Import/Export support (JSON & CSV).
*   **🎯 Soft Limits:** Set daily distraction caps. The UI reacts when you exceed them.
*   **📱 Responsive:** Optimized for Desktop, Tablet, and Mobile.

## 🚀 Quick Start ( < 60 Seconds )

You have three ways to use Distraction Ledger. Choose the one that fits your workflow.

### Method 1: Hosted (Easiest)
Simply visit the GitHub Pages link. The app caches itself and works offline after the first load.
> **[Open Distraction Ledger](https://aliriyaj007.github.io/Distraction-Ledger/)**

### Method 2: Local File (Privacy Max)
1.  Download the `index.html`.
2.  Disconnect from the internet (optional).
3.  Open `index.html` in Chrome, Firefox, Safari, or Edge.

### Method 3: Developer Clone
```bash
git clone https://github.com/Aliriyaj007/Distraction-Ledger.git
cd Distraction-Ledger
# Open index.html in your browser
open index.html
```

## 🛠 Usage Guide

1.  **Pin it:** Pin the tab in your browser or bookmark it.
2.  **Work:** Do your deep work.
3.  **Log:** When you catch yourself scrolling or wandering, switch tabs and click the corresponding category (e.g., *Phone*, *Social Media*).
4.  **Reflect:** At the end of the day, check the **Analytics** tab to see your "Peak Distraction Hours."
5.  **Export:** Weekly, export your data to CSV for long-term archiving.
